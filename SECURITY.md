# Security

Quack handles API tokens and credentials, so security reports are taken seriously.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/itsmunzir/quack/security/advisories/new) instead.

Include what you found, how to reproduce it, and which version and operating system you used.
You'll get a reply within a few days, and credit in the release notes once it's fixed, if you'd like.

## Supported versions

Fixes go into the latest release. Please update before reporting.
